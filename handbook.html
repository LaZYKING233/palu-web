01 / 关于AI第一章 · 关于 AI

目标：把 LLM、Harness、Agent 这三个在 2026 年反复出现的概念讲清楚，并列出本方向最常用的一些编程语言。

LLM（Large Language Model，大语言模型）：基于 Transformer 架构、在海量文本上预训练的概率模型。给定一段上下文，预测下一个 token，并以此生成连贯的自然语言或代码。它不检索事实，生成的是「最像合理继续」的文本，所以在事实性、数学性、确定性任务上可能出错，需要外部工具或人来兜底。2026 年的主流 LLM 已经普遍具备：长上下文（数十万到百万 token 量级）、工具调用（function calling / tool use）、多模态输入（文本 + 图像 + 音频 + 视频）、结构化输出（JSON / 代码）。这些能力本身不等于「Agent」，它们是 Agent 用来决策的「大脑」。

Harness：包裹在 LLM 外面的运行时基础设施。2026 年流行的总结是 Agent = Model + Harness。LLM 本身是无状态的，不会主动调工具，也不保证自己写出的代码能跑；Harness 负责把这些事补上（管理会话、调度工具、维护上下文、持久化状态、隔离沙箱、设置权限与护栏）。判断一个系统是不是 Harness 的四个必要条件（arXiv 2606.10106）：① Agent Loop（推理 → 行动 → 观察 → 再推理的循环）；② Tool Interface（让模型能感知并修改外部环境）；③ Context Management（主动管理流入流出的信息）；④ Control Mechanisms（不依赖模型「愿不愿意服从」的限制、验证器、确定性处理）。LangGraph / CrewAI / AutoGen 这类「框架」是用来构建 Harness 的工厂，不是 Harness；Claude Agent SDK / OpenAI Agents SDK 是零件，不是 Harness。真正的 Harness 实例：Claude Code、Codex CLI、Aider、Cline、OpenHands、SWE-agent、Hermes Agent 等。

Agent：「LLM + Harness」组合之后跑起来的系统形态。给定一个目标，自己决定下一步做什么、调用哪些工具、怎么验证结果，直到目标完成或触发停止条件。Agent 与「聊天机器人」、「RAG 检索增强」的根本差异是自治度：聊天机器人只回答一次；RAG 检索完就生成回答；Agent 检索、决策、执行、观察、再决策。2026 年主流 Agent 架构的四个角色：Planner（拆目标为子目标）、Executor（在当前状态下决定调用哪个工具的 LLM 调用，token 消耗大头）、Memory（短期 = 上下文窗口里的对话缓冲，长期 = 向量库/结构化数据库/文件）、Tools（网页搜索、代码解释器、数据库查询、文件操作、API、其他 Agent）。Anthropic 2024 年 12 月的《Building Effective Agents》还区分了 Agentic Workflow（开发者写好图，LLM 在节点里填内容）和 AI Agent（LLM 在运行时自己决定图的下一条边）。

常用语言（按本项目使用频率排序）：JavaScript / TypeScript（小程序前端与构建工具链的事实标准）、Python（AI 工具链的事实标准：训练、推理、评测、agent 编排）、PHP（本项目后端云函数与 API）、SQL（从 PostgreSQL / MySQL 取数）、Shell（bash / PowerShell，构建、部署、调试绕不开）、Rust（新一代 AI 基础设施语言，Hermes Agent 本身、llama.cpp、tokenizers、Polars 等）、C / C++（底层推理引擎实现语言）、Mojo（Modular 出品、Python 语法的超集、能编译到原生机器码，2026 年仍是早期阶段）、Julia（科学计算与数值分析方向的语言）。入门优先级：JavaScript / TypeScript 与 Python 先扎实；SQL 与 Shell 同步学；PHP 看后端代码时跟着读；Rust / C++ 在真正碰到性能瓶颈或读底层代码时再深入；Mojo / Julia 了解即可。

02 / ChatGPT第二章 · 购买 ChatGPT

目标：完成 ChatGPT 账号注册、选择适合自己的订阅档位（Free / Plus / Team / Pro）、完成首次支付，并把 ChatGPT 用到至少一个真实任务里。

为什么专门讲 ChatGPT 的购买方式。一方面是因为这个不是国内的；另一方面是它便宜而且好用。

三种购买方案

前提：三种方案都要求自备稳定的网络环境（俗称「梯子」），并且需要海外 IP 才能完成支付与订阅。请先把网络环境确认好再开始操作。

方案 A海外 Apple ID + App Store 内购

方案一的主要流程是，海外 apple id → 下载 chatgpt → 支付方式选择无 → 应用内购。

大家可以去网上找一找视频教程，文字写的不是很清楚可能。我自己也有一些遗忘了。

然后我会一步一步讲，在开始之前最好先在电脑上挂上梯子（以防万一），最好选择美区。

关于地区的选择，首先你要看这样的两个网站，第一个：App Store Price - 发现全球 App Store 最低价，这个是看各个地区的 chatgpt 的订阅价格的，然后第二个：SEAGM - 全球华人首选线上游戏点卡, 购物礼品卡, 手游和直播充值直充平台，这个是用于看你可以买什么地区礼品卡的（我们会选择用礼品卡充值，其他的没有搞出来过）。选择美区的原因就是：

首先不是很贵，其次你买得到，然后就是社区完善，大家都教你怎么在美区买，你遇见问题了，可以参考的资料多。

本人经历避雷加拿大，当然日本也没有成功过。

首先就是一个 apple id，注意你的这个 apple id 是需要一个海外的（网址：Apple 账户：登录与管理）。

  • 如果你有自己的国内的 apple id，你可以考虑转区。
  • 当然你也可以自己新注册一个，全程没有梯子要求和乱七八糟要求，就直接 +86 手机号和自己的 qq 邮箱都可以。

注册的时候可能会让你写支付地址这些啥的，这个时候如果你有梯子的话，正常而言会有一个选项是无支付方式。你就选择那个就好了，如果有地址的话，需要一个美国免税州（打开你的浏览器，搜索美国免税州地址生成器）。

这个时候第一步算是结束了，然后第二步就是，你需要登录上你的这个海外的 apple id 到你的 app store（希望你找得到在什么地方退出 app store 和登录……）

如果你没有梯子，你可能需要一个 UU 加速器，然后加速一下你的 app store，之后你最好先充个几刀，先去买一个小火箭，或者用免费的（但是那个非常糟糕）。然后梯子的话，你没有再找我们吧。

然后下载 chatgpt！（没有的话，那就是你的号肯定不是海外的号，注意香港也是封禁的）

之后登录一下自己的 chatgpt 账号，当然了，你需要先注册（https://chatgpt.com）。

这个时候回到自己的 app store，然后点右上角自己的头像，你需要找到自己的支付方式（payment methods），把付款方式修改为无（none），地址（billing address）需要写的话，同你在之前在电脑上写的免税州地址一样（之前没有写就不用管了，这个写了就行），注意一定是支付方式是无 + 免税州。

然后去买礼品卡，再打开 app 内购。

如果你 fail 了，那就是你的号被风控了。解决方案如下，你先下一个 apple support，然后去设置（注意是手机的设置里面嗷）里面，修改你的地区和语音，修改为美国，语言是英语。然后你用 apple support，去和客服对线（注意你得说英语，我知道大家的英语一定都很好，所以应该问题不大），正常来说，客服会和你说等个几天就好了，你就老老实实等着，到了时间就去再试试，应该就好了。

方案 BGoogle Play + VISA 卡

这个方案适用于安卓用户们。

在正式开始之前，需要确保自己有这样的东西：谷歌账号，自己的手机上可以下载和打开谷歌商店，visa 卡。

关于谷歌的部分得大家自行解决，因为谷歌后面政策有收紧，我们的谷歌号都有好几年了。所以现在的注册方案我也不是很清楚。然后下载和使用谷歌商店，因为我们是小米，所以也自带，其他机型和品牌不了解。

关于 visa 卡，可以参考这个视频：【最详细的外币卡办理教学（别惦记你那破虚拟卡了，不怕跑路啊）】。

本人使用的是招商银行的万事达卡，去的时候需要带自己的学生证和身份证，其他都不需要，过程非常方便和流畅。

另外的我本人使用、验证过的视频，截止 2026.9.11，均被下架。

上面三者都具备之后。开始操作。

首先打开谷歌 play，先直接搜 chatgpt。

如果你没有，OK，那就点自己的右上角的头像，点设置。常规 - 账号和设备偏好设置 - 国家/地区和个人资料，你看看自己的 play 商店，是不是美国的（反正不能是香港）。如果是香港的话，那你先去挂一个美国节点的梯子，这个时候应该就可以直接切到美国的 play 商店，如果还是没有！那就先往下看。

方案 C虚拟卡

首先我必须声明一下：这个渠道是最不安全，风险最高的，大家谨慎考虑。

首先我们需要准备这样的一些东西，币安，和一个虚拟卡的平台（这里我使用的是 mpchat）。

到了这里，就有必要先讲一下为什么要用虚拟卡。因为 openai 的用的那个认证的公司，那个平台会拒绝中国发的卡，所以我们要用一个其他地区的卡。为什么上面用 google pay 就可以呢，因为 google pay 在中间中转，那个认证平台拿不到这张卡是什么地区发行的，所以可以支付。

然后就是说一下整个流程，用虚拟卡，给虚拟卡充 USDT（这是一种虚拟币，看名字就知道，金额上约等于一美刀），所以到时候在中间都会需要进行多次的中转，这些中转都需要手续费。比方说 CNY 买 USDT，转出需要手续费，USDT 转美刀需要手续费，美刀转其他货币需要手续费。

然后你用虚拟卡的话，你就需要在这些平台上上传自己的身份证和人脸信息。

具体的操作参考这个 docx 和这个视频吧：【2026最新｜低价GPT Plus菲区订阅充值教程：982比索≈d107元，虚拟卡实测成功】。

然后我补充一点，usdt 交易本质上是你和其他有这个货币的人交易，所以需要用到自己的微信和支付宝，需要和商家进行交流。
