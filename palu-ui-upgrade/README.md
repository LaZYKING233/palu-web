# 校园帕鲁首页 / 个人中心 UI 演示

直接用浏览器打开 `index.html`，无需安装依赖、启动服务或连接网络。HTML、CSS、JavaScript 放在同一目录即可。

设计基于 `E:\HBws2025\work` 当前首页、个人中心内容模板、页面 definition 和自定义底栏。没有修改小程序源码，也没有提交、发布网站。全部账号、课程、余额与通知数据为虚构示例。

## 设计与操作

- 校园蓝 `#376AE5`、云白 `#F6F8FC`、深蓝文字 `#20334C`、辅助灰 `#738197`；红黄绿只表达账户状态。
- 中文采用系统雅黑 / 苹方，标题搭配 Trebuchet MS，数字使用 Bahnschrift；不依赖远程字体。
- 首页保留左上角校园卡、照明、空调三枚状态灯；点击展开金额、免费与收费电量、查询时间和刷新按钮。未绑定宿舍显示独立状态。
- 今日课程采用时间轴，周标跳转校历，完整课表弹窗包含周一至周日。考试保留日期、时间、地点、座位、状态和倒计时。
- 个人中心按身份信息、校园网、校园服务、辅助服务分组；功能清单直接显示，不收入“更多”。向下滚动可见全部辅助服务。
- 顶部切换学生、教师、新生、未登录、管理员，以及空数据、登录过期、宿舍未绑定状态。管理员预览是学生身份叠加管理权限，不是新的业务身份。
- 右上角圆形按钮切换深浅色。手机通过底栏切换页面；宽度超过 650px 并排展示两页，用于桌面与平板方案预览。
- 设置中可调整最多两个底栏快捷入口，按演示身份独立保存于当前内存。刷新网页恢复初始演示。

## 原型边界

本次交付是首页与个人中心的设计原型。已有业务入口弹出名称和原页面路径，未重做后续业务页面；二维码、校园地图及客服保留入口与展示位置，不加载真实服务。原生产鉴权、财务授权、验证码服务、接口数据与角色权限逻辑需要在正式接入时沿用。

会员卡示例展示 Premium，正式实现需保留 Ultra 分支；课程节假日提示、学期未开始文案、后台动态通知和待办内容沿用原条件与数据。本原型提供主要状态的设计，不等同于全部生产状态机。

## 验证

`verify.cjs` 为当前机器的浏览器验收脚本（使用已有 Playwright 与 Edge，不是页面运行依赖）。运行 `node verify.cjs` 检查五种身份入口、四种状态切换、320/390/768/1024/1440px 文档横向溢出、余额弹窗、校园网验证码、快捷入口设置与手机页面切换，并捕捉 JavaScript 错误。
