# 校园帕鲁网站

校园帕鲁工作室的公开网站，用于介绍小程序、发布公告与更新日志，并承载招新信息与技术部的公开学习文档。

## 本地预览

这是一个无构建依赖的静态网站，直接用浏览器打开 `index.html` 即可预览；也可以使用任意静态文件服务器托管本目录。

## 文件结构

- `index.html`：网站内容与语义结构
- `development.html` / `operations.html` / `support.html`：各部介绍页
- `handbook.html`：**Vibe Coding 学习指南**（公开文档，见下）
- `styles.css`：视觉、响应式布局与动效
- `script.js`：移动导航、滚动状态、渐入效果、章节展开
- `404.html`：GitHub Pages 的错误页
- `docs/`：其他部门文档（如客服话术）
- `email-templates/`：新人欢迎邮件模板
- `assets/`：站点图标与图片

## 学习文档（handbook.html）

面向所有人的 AI 编程入门文档，零基础可读，公开访问。按三步组织，共六章：

| 阶段 | 章节 |
| --- | --- |
| 一、先把工具用上 | 01 关于 AI（LLM / Harness / Agent / 常用语言）· 02 购买 ChatGPT |
| 二、学会跟 AI 干活 | 03 Harness：让 AI 真正动手 · 04 Skill 与 MCP · 05 提示词写法 |
| 三、让成果留下来 | 06 Git 与 GitHub 团队的公共记忆 |

结尾有一节「怎么成为一个好的 vibe coder」，把六章压缩成六条原则。

**维护约定**

- 面向非技术读者：概念第一次出现要解释，长段落拆成短段落、列表、表格和提示框，不要堆成大段文字。
- 涉及具体产品（版本、价格、订阅档位、命令）时以官方文档为准，注明核实时间。AI 工具迭代很快，写死的事实要定期复查。
- 排版用 `.ch-body` 内的既有组件：`.cards`（概念卡）、`.terms`（名词表）、`.steps`（步骤）、`.note` / `.note-warn`（提示与警告）、`.vs`（好/坏对照）、`.table-wrap`（表格）、`pre`（命令与代码）。不要引入行内样式。
- 新增章节：复制一个 `<details>`，给它 `id="ch-0X"`，并同步更新「怎么读」里的 `.path-list` 和 `.ch-index` 两处目录。

## 内容维护

公告、更新日志和招新信息目前直接维护在 `index.html`，避免首版引入不必要的内容系统。正式发布前需要补充：

- 招新群二维码
- 对外联系渠道
- 团队成员信息（如果决定公开）

网站端的正式发布改动应先在测试分支完成验证，确认无误后再进入 `main`。不要未经确认直接向 `main` 提交或推送。
