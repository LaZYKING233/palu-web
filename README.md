# 校园帕鲁网站

校园帕鲁工作室的公开网站，用于介绍小程序、发布公告与更新日志，并承载招新信息。

## 本地预览

这是一个无构建依赖的静态网站，直接用浏览器打开 `index.html` 即可预览；也可以使用任意静态文件服务器托管本目录。

## 文件结构

- `index.html`：网站内容与语义结构
- `styles.css`：视觉、响应式布局与动效
- `script.js`：移动导航、滚动状态与渐入效果
- `404.html`：GitHub Pages 的错误页
- `assets/favicon.svg`：站点图标

## 内容维护

公告、更新日志和招新信息目前直接维护在 `index.html`，避免首版引入不必要的内容系统。正式发布前需要补充：

- 招新群二维码
- 对外联系渠道
- 团队成员信息（如果决定公开）

## 目录边界

- `E:\HBws2025\web`：网站端部署相关代码、配置与文档。
- `E:\HBws2025\work`：校园帕鲁微信小程序的正式开发目录。
- `E:\HBws2025\new\campus-palu`：小程序的个人测试与创意验证目录。

网站端与小程序端分开维护。

## 发布原则

网站端的正式发布改动应先在测试分支完成验证，确认无误后再进入 `main`。不要未经确认直接向 `main` 提交或推送。
