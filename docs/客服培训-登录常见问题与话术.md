# 客服培训：登录常见问题与话术

本文用于处理校园账号绑定、登录和验证码相关咨询。回复时不要索要或让用户发送密码、验证码、Cookie、会话 ID 等敏感信息；如需技术排查，只记录学号、报错原文、出现时间和是否更换网络，不要记录密码。

## 1. 请填写完整信息

**原因：** 用户没有填写校园账号或统一身份认证密码，系统未发起登录请求。

**建议回复：**

“请检查校园账号和密码是否都已填写完整，再点击登录。密码不用发给我们。如果确认已填写仍然提示此信息，请把报错截图和出现时间发来，我们再继续帮您排查。”

## 2. 请先阅读并同意用户协议

**原因：** 登录前的用户协议勾选项未选中，系统会阻止继续登录。

**建议回复：**

“请先阅读登录页面的用户协议，并勾选‘同意’后再尝试登录。如果页面没有显示勾选项或勾选后仍无法继续，请把页面截图发来。”

## 3. 账号或密码错误 / 教务系统用户名或密码错误

**可能出现的提示：**

- `账号或密码错误，请检查后重试。`
- `教务系统用户名或密码错误`
- `WebVPN账号或密码错误，或教务系统暂不可用`

**原因：** 最常见的原因是校园账号、统一身份认证密码输入错误，或账号当前无法通过 WebVPN/教务系统认证。后一条提示也可能表示教务系统暂时不可用，不能仅凭提示断定一定是用户密码错误。

**建议回复：**

“请先确认填写的是学校统一身份认证的账号和密码，注意账号前后不要有空格，密码大小写和特殊字符要保持一致。请不要把密码发给我们。若确认账号密码无误仍无法登录，或很多用户同时遇到相同问题，请把报错原文、出现时间和网络环境发来，我们帮您核实教务系统是否暂时异常。”

## 4. 无法获取验证码，可能是账号或密码错误，请检查后重新登录

**原因：** 第一步登录没有成功建立到 WebVPN/教务系统的有效连接，因此系统无法进入获取验证码的页面。常见原因是账号密码错误，也可能是上游登录页暂时不可用。

**建议回复：**

“请返回第一步，重新输入校园账号和密码后再获取验证码。若确认账号密码无误仍无法获取验证码，请稍后重试一次；如果仍然失败，请提供报错原文、出现时间和是否使用校园网，我们转给技术人员检查。”

## 5. 自动识别未通过，请手动输入新验证码

**原因：** 系统自动识别验证码没有得到有效结果。这通常是验证码图片较模糊、字符粘连或识别服务本次未成功，不代表账号或密码一定错误。

**建议回复：**

“这是验证码自动识别没有通过，不一定是账号或密码错误。请直接按照页面显示的新验证码手动输入，注意区分字母大小写和数字；如果看不清，请重新获取一张验证码。连续多次看不清时，请把验证码区域的显示情况和报错时间发来。”

## 6. 请输入验证码 / 手动验证码格式无效

**原因：** 用户没有填写验证码，或填写内容不是系统要求的验证码格式。验证码应以当前页面显示的内容为准，不要继续使用旧验证码。

**建议回复：**

“请填写当前页面显示的验证码后再提交。若验证码看不清，请先重新获取验证码；输入时不要添加空格，也不要使用上一张验证码。请不要把验证码发送给客服。”

## 7. 验证码错误 / 用户名或密码或验证码错误

**原因：** 当前验证码与服务器不一致，或者验证码已过期；部分情况下，教务系统会把账号、密码和验证码错误合并显示，无法仅靠这条提示判断具体是哪一项。

**建议回复：**

“请重新获取验证码，并使用最新显示的验证码提交一次。输入时注意字母大小写、数字和相似字符；如果连续两次仍提示错误，再检查账号密码是否正确。不要重复提交同一张旧验证码，也不要把密码或验证码发给我们。”

## 8. 会话已过期，请重新登录 / 会话失效，请重新登录

**原因：** 第一步生成的临时登录会话已过期、失效，或本地保存的登录状态与服务器不一致。此时继续提交原来的验证码不会成功。

**建议回复：**

“当前登录会话已经失效，请返回登录页，从第一步重新输入账号和密码并获取新的验证码，再完成登录。请不要继续使用之前的验证码。如果每次刚获取验证码就立即提示会话失效，请把出现时间和网络环境发来，我们帮您排查。”

## 9. 网络错误，请检查网络

**可能出现的提示：**

- `网络错误，请检查网络`
- `网络错误：……`
- `WebVPN登录页不可用，请稍后重试`
- `WebVPN登录请求失败，请稍后重试`

**原因：** 小程序到服务器、WebVPN 或教务系统之间的请求没有正常完成，可能与本地网络、校园网限制、上游系统临时故障或服务超时有关。这类提示不能直接说明账号密码错误。

**建议回复：**

“这次提示属于网络或上游服务连接异常，不一定是账号密码问题。请先切换一次 Wi-Fi/移动网络后重试，确认微信可以正常联网；如果仍然失败，请稍后再试，并把完整报错、出现时间和当前网络环境发来。多人同时出现时，我们会统一转技术人员核查。”

## 10. 验证失败：验证码错误或信息获取失败，请重新获取验证码并登录

**原因：** 登录提交后，系统没有正常取得完整的校园账号资料（例如姓名、学院或身份信息），因此无法完成绑定。可能是验证码提交未被教务系统接受，也可能是教务系统资料页暂时返回异常。

**建议回复：**

“系统暂时没有获取到完整的校园账号资料，请重新获取验证码并完整登录一次。若确认验证码输入正确仍重复出现，请不要反复尝试，把报错原文、出现时间和账号所属身份（学生/教师）发来，我们转技术人员核查。”

## 11. 无法确认校园账号身份，请重新登录

**原因：** 教务系统看起来完成了登录，但返回的个人资料或身份信息不完整，系统无法确认当前账号属于哪个校园身份。

**建议回复：**

“系统暂时没有确认到完整的校园身份信息，请从第一步重新登录一次。若仍然提示此错误，请提供报错原文、出现时间以及您是学生还是教师，我们需要进一步检查教务系统返回的资料。”

## 12. 当前账号未缴费或未注册，请先处理账号状态

**原因：** 教务系统返回的账号状态不可用，通常表示账号尚未注册、未完成相关缴费或被上游系统限制登录。客服不能通过小程序直接修改这类校园账号状态。

**建议回复：**

“教务系统返回的账号状态暂不可用，请先到学校官方渠道确认账号是否已注册、是否需要完成缴费或激活。处理完成后再回到小程序登录。如果学校官方渠道确认账号状态正常但这里仍提示此信息，请把报错原文和出现时间发来，我们继续核查。”

## 13. 教务系统身份标签未识别收录，请联系客服处理

**原因：** 登录成功后，系统读到了新的身份标签，但当前版本还没有收录或匹配该身份类型，属于系统配置兼容问题，不是用户输入错误。

**建议回复：**

“这是系统暂未识别当前校园身份类型，不是您操作错误。请提供报错原文、出现时间和账号身份（不要发送密码、验证码或登录凭据），我们登记后交由技术人员处理。”

## 14. 保存登录会话失败，请稍后重试

**原因：** 账号认证可能已经完成，但服务器没有成功保存本次登录会话，因此小程序无法继续使用这次登录结果，属于服务端异常。

**建议回复：**

“本次认证结果没有成功保存，请稍后重新登录一次。若连续出现相同提示，请不要反复提交密码，把完整报错、出现时间和网络环境发来，我们交给技术人员检查服务状态。”

## 客服判断与升级标准

1. 只出现一次、且属于验证码或会话问题：先引导用户重新获取验证码或从第一步重新登录。
2. 明确是账号状态、身份标签或资料确认问题：记录报错原文后升级，不要让用户反复尝试。
3. 多名用户在同一时间出现网络、WebVPN、验证码图片获取失败等提示：优先按系统异常升级，并记录集中出现的时间段。
4. 不向用户索要密码、验证码、Cookie、会话 ID 或完整登录页面截图；如需截图，提醒用户先遮挡个人敏感信息。
